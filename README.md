# Fart Synth

A physically-modeled fart synthesizer VST3 for FL Studio (and anything else that loads VST3), by TYF.

- Self-oscillating sphincter valve + resonant tract model — real control over pressure envelope, tone and texture
- Play it with MIDI (C3 = base pitch) or hold the butt in the plugin window
- Butt-shaped UI with a reactive visualizer

## Download

Every push to `main` builds the plugin on GitHub Actions. Grab the latest from the **Releases** page (`latest`):

1. Download `FartSynth-VST3-Windows.zip` and unzip it
2. Move the `Fart Synth.vst3` folder into `C:\Program Files\Common Files\VST3`
3. In FL Studio: Options → Manage plugins → Find plugins

`FartSynth-Standalone-Windows.zip` is a standalone app version.

`index.html` is the original browser prototype.
